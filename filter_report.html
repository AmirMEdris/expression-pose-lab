Model & dataset

Distribution of the strongest response in each scanned image. Compare numbers within this filter only; different filters have different scales.

1. Strongest real examples

Six distinct dataset images with the highest peak response for this filter. These are original dataset pixels, not generated inputs. FER2013 also contains some graphics and poor-quality images.

Box = the possible input support of that peak unit. It is not an attention map, and not every pixel inside must matter.

2. Similar brightness, lower response

Lower-response examples chosen from the closest 12.5% in global brightness and contrast to the strongest image. This controls two simple confounds, not facial pose or semantic content.

3. One filter, three targeted Dreams

Each Dream maximizes one fixed spatial unit of this filter. The unit is selected before optimization and kept fixed. It does not maximize all layers or an expression class.

What is verified?

The displayed final PNG pixels are fed back through the model. “Verified increase” means that exact unit’s response rose. That proves the response change—not that the pattern is an eye, that it is natural, or that it caused an expression prediction.

Different seeds may produce different patterns. If they disagree, the interpretation is inconclusive. More Dream intensity does not establish more meaning.

Reproducible method and limits

Layer coordinates and source image indices are stored in the adjacent evidence JSON; the raw images and responses are in the NPZ file. Structural receptive fields are calculated through convolutions, pooling and supported residual branches. Deep units may cover nearly the entire face, limiting localization.

Validation images are used for inspection, not a fresh generalization test. The recovered baseline’s original training exposure is unknown. Exact duplicates were removed; near-duplicate and identity-disjoint audits have not been performed. Global brightness/contrast matching is not a semantic specificity test. Human feature annotations and controlled feature interventions would be needed to support a label such as “eye detector.” Convolution outputs are measured at that layer: a built-in activation is included; a following separate normalization or activation layer is not.
